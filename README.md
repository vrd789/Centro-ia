# CENTRO IA 1.0

## Descripción
Plataforma de coordinación de múltiples inteligencias artificiales.

## Objetivo
Crear un sistema capaz de conectar diferentes modelos de IA para investigar, programar, analizar y resolver problemas conjuntamente.

## Inteligencias artificiales
- ChatGPT
- Google Gemini
- DeepSeek

## Componentes
- Coordinador principal
- Conexiones API
- Memoria compartida
- Agentes especializados
- Interfaz unificada
- Sistema de seguridad

## Estado
Fase inicial de desarrollo.
